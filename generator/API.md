# Серверлік интеграция интерфейсі

Бұл жинақта backend жоқ. HTML сабақтар ешбір нәтижені серверге жібермейді. Жауаптар тек браузердің localStorage қоймасында сақталады. «Нәтижені JSON түрінде жүктеу» жергілікті файл береді.

Болашақ API: `POST /v1/attempts`, HTTPS, `Content-Type: application/json`. Аутентификация қажет ортада `Authorization: Bearer …` тақырыбы пайдаланылады. Токендерді HTML ішіне жазбаңыз.

Сұрау мысалы:

```json
{
  "schema_version": "1.0",
  "topic_code": "U1.1",
  "answers": {"U1.1-01": 0, "U1.1-02": 4},
  "completed_at": "2026-11-09T12:00:00Z",
  "score": 2,
  "total": 15
}
```

Жауап нұсқаларының индекстері нөлден басталады. Сервер `score` өрісіне сенбей, өзіндегі quiz.json кілтімен қайта есептеуі керек. Клиент сағаты мен `completed_at` сенімді уақыт көзі емес. Сервер пайдаланушыны аутентификациядан анықтап, сақтау уақытын өзі тіркейді.

Сәтті жауап: HTTP 201, `{"attempt_id":"generated-id","score":2,"total":15,"saved_at":"ISO-8601"}`. Қате пішім: 400; авторизация жоқ: 401; рұқсат жоқ: 403; тым көп сұрау: 429; сақтау қатесі: 500. Қайталап жіберуді қауіпсіз ету үшін idempotency key қосуға болады.

`api-client.js` — интеграцияға арналған көмекші модуль. Ол сабақтарға қосылмаған. Нақты endpoint, аутентификация, CORS және серверлік валидация дайын болғанда ғана қосыңыз. Клиентте жауап кілті бар болғандықтан бұл оқу интерфейсі қорғалған емтихан жүйесін алмастырмайды.
