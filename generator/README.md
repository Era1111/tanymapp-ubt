# Қайта қолданылатын оқу материалы генераторы

Бұл генератор тексерілген `course.json` мазмұнын бес форматқа шығарады. Ол PDF-ті автоматты түрде оқып, жаңа ғылыми мазмұн немесе тест ойлап таппайды. Жаңа тақырып үшін мәтін, дереккөз беттері, сұрақтар мен дұрыс жауаптарды автор енгізеді.

## Тәуелділіктер

- Python 3.11 немесе жаңарақ, `reportlab`.
- Times New Roman қаріптерінің лицензияланған `Times New Roman.ttf`, `Times New Roman Bold.ttf`, `Times New Roman Italic.ttf` файлдары.
- Node.js және осы ортада қолжетімді `@oai/artifact-tool` кітапханасы. Бұл Codex ортасының жеке кітапханасы; жалпы npm репозиторийінен міндетті түрде орнатылады деп есептемеңіз.
- LibreOffice `soffice`: PPTX-тен PDF шығару үшін.

Қаріптер macOS-тың `/System/Library/Fonts/Supplemental` бумасынан алынады. Басқа ортада `COURSE_FONT_DIR` айнымалысын орнатыңыз. Қаріп файлдары жинаққа енгізілген жоқ.

## Іске қосу

Жинақтың түбірінен:

```sh
python3 generator/generate.py --course generator/course.json --out rebuilt
```

Жаңа, бөлек `--out` бумасын таңдаңыз. Node және LibreOffice орындарын `--node` және `--soffice` арқылы беруге болады. Артефакт кітапханасы басқа жерде болса, `COURSE_NODE_MODULES` айнымалысын сол `node_modules` бумасына бағыттаңыз. `COURSE_BUILD_DIR` аралық PPTX файлдарына арналған буманы белгілейді.

PPTX кітапханасы қолжетімсіз ортада:

```sh
python3 generator/generate.py --course generator/course.json --out rebuilt --skip-pptx
```

Бұл режим HTML, SVG, JSON, textbook.pdf және teacher_guide.pdf жасайды. lesson.pptx пен lesson.pdf бұл режимде жасалмайды.

Codex ортасының қосымша валидаторларын қосу үшін `COURSE_PRESENTATION_SKILL` және `COURSE_PYTHON` беріледі. Әр тексеруге жаңа build және output бумаларын пайдаланыңыз. Қалыпты сыртқы іске қосуда бұл айнымалылар қажет емес, бірақ визуалды тексеру бәрібір қажет.

## Жаңа тақырып енгізу

`course.json` ішіндегі `lessons` массивіне осы құрылымдағы жаңа нысан қосыңыз:

- `code`, `slug`, `title`: бірегей код, қауіпсіз бума атауы, тақырып.
- `goals`, `prerequisites`: оқу мақсаттары мен алдыңғы білім.
- `sections`: `{title, text, source}` теория блоктары.
- `table`: бірінші жолы тақырыптар болатын мәтіндік кесте.
- `examples`: `{question, steps}` қадамдық мысалдар.
- `practice`: A, B, C үшін `{level, question, answer}`.
- `quiz`: 15 тапсырма; әр деңгейге бес. `options` — бес әртүрлі жол, `answer_index` — 0–4, `correct_answer` — A–E, `option_explanations` — бес түсіндірме. `id`, `level`, `topic_code`, `skill`, `question`, `explanation` міндетті.
- `errors`, `summary`: қателер мен қорытынды.
- `cards`: сұрақ–жауап жұптары.
- `diagram`: төрт қысқа атау, `diagram_caption`: байланыстардың ғылыми түсіндірмесі. Қазіргі макет төрт түйінді сызбаға арналған. Басқа сызба түрі үшін SVG және слайд макетін кеңейтіңіз.
- `references`: дереккөз ID → нақты беттер. `books` ішінде басылым метадеректері сақталады.

Қазіргі PPTX макеті 4 теория блогы, 3 мысал, 3 практика және 4 түйінді сызба үшін тексерілген. Көлемі ұзын тақырып қосылса, слайдқа сыйымдылығын қайта тексеріңіз. Генератор барлық жаңа мәтінге мінсіз макетке кепілдік бермейді.

## Тексеру

Жинақтың дайын файлдары үшін:

```sh
python3 generator/validate.py
```

Бұл 75 сұрақтың құрылымын және 37 сандық жауапты тәуелсіз формуламен тексереді. Семантикалық бірмәнділік, ғылыми дұрыстық және жаңа тақырыптағы есептерді автор бөлек тексеруі қажет. Қазіргі сандық тексерулер осы бес сабаққа арналған.

Бір тақырыпты толық қайта құрастыру осы ортада орындалып тексерілді. HTML браузерлік визуалды тексеруі орта қауіпсіздігіне байланысты аяқталмады. JavaScript-тің жауап таңдау, балл есептеу, бос жауаптан қорғау және жергілікті күйді қайта жүктеу логикасы жеке DOM сынақ ортасында тексерілді.

`API.md` және `api-client.js` болашақ серверлік интеграцияға арналған. Нақты сервер бұл жинаққа кірмейді.
