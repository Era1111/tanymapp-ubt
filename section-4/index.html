САБАҚ 01

Бағдарлама қалай шешім қабылдайды?

Шарт — True немесе False

if артындағы өрнек ақиқат болса, одан кейін шегініспен жазылған блок орындалады. Жалған болса, elif тексеріледі, соңында else қалады. Python-да блоктың басталуы қос нүкте және шегініс арқылы анықталады.

score = 67
if score >= 50:
    print("Өтті")
else:
    print("Қайтала")

67 ≥ 50 → нәтиже «Өтті». else шарт жазылмайды.

САБАҚ 02

Шарттарды біріктір

andЕкі шарт та ақиқатTrue ∧ True → True
orКемінде бірі ақиқатFalse ∨ True → True
notМәнді терістейдіnot False → True

Шекараны мұқият оқы

10 <= x <= 99 — x екі шекараны қоса алғанда аралықта. x > 10 and x < 99 — 10 мен 99 кірмейді. == мәндерді салыстырады, = айнымалыға мән меншіктейді.

age >= 16 and has_ticket өрнегі билет бар әрі жас жеткілікті кезде ғана True болады. not has_ticket билет жоқ жағдайды білдіреді.

САБАҚ 03

Бірнеше тармақты дұрыс ретте

Жоғары шектен баста

Бағаны 90, 75, 50 шектерімен қойғанда алдымен ең үлкен шекті тексер. Егер score >= 50 бірінші тұрса, 95 те сол тармаққа түсіп, жоғары бағаға жетпейді.

if score >= 90:
    grade = "A"
elif score >= 75:
    grade = "B"
elif score >= 50:
    grade = "C"
else:
    grade = "D"

Күрделі тармақты ішкі if арқылы жазуға болады, бірақ бір деңгейдегі өзара бөлек жағдайға elif оқуға жеңілірек.

≥ 90 A
≥ 75 B
≥ 50 C
қалғаны D

with open — сенімді үлгі

with open("input.txt", encoding="utf-8") as f:
    numbers = list(map(int, f.read().split()))
print(sum(numbers))

read() бүкіл файлды бір мәтін ретінде оқиды; readline() бір жолды оқиды; readlines() жолдар тізімін қайтарады. split() бос орындармен бөледі. with блок соңында файлды автоматты жабады.

Егер input.txt табылмаса, оны main.py орналасқан жобаға қос. Файл аты мен әріп регистрін дәл жаз.

Мына мысалды басынан аяғына дейін қайтала

Мақсат: input.txt ішіндегі 2 4 6 9 сандарын қосу, 21 нәтижесін экранға шығару және output.txt файлына сақтау.

OnlineGDB-ді ашуФайл қосу және жүктеу үшін ұсынамызReplit те қолжетімді
  1. Python редакторын аш. OnlineGDB бетінде main.py файлы дайын ашылады. Ішіндегі бастапқы мысал кодты толық өшір.
  2. Кіріс файлын қос. Үстіңгі жақтағы файл белгішесін бас немесе Ctrl+M пернелерін қолдан. Жаңа файлдың атын дәл input.txt деп жаз.
  3. Деректі енгіз. input.txt ішіне төмендегі бір жолды жаз. Содан кейін main.py қойындысына қайта орал.
  4. Толық кодты көшір. Төмендегі кодтың бәрін main.py ішіне қой. Бос орындар мен шегіністерді сақта.
  5. Іске қос. Run батырмасын бас. Нәтиже аймағында 21 шығуы тиіс. Файлдар тізімінде жасалған output.txt файлын ашып, онда да 21 екенін тексер.
  6. Өзіңді тексер. Төмендегі 16-тапсырмаға өтіп, «Өзің алған нәтиже» өрісіне 21 жаз да, тексеру батырмасын бас.

PYTHON · НӨЛДЕН БАСТА

Кодтағы әр белгі не істейді?

Әр мысалды жеке іске қосып көр. Алдымен кодты оқы, нәтижені болжап, кейін тексер.

Енгізу және шығару

input() пернетақтадан мәтін алады. int(...) сол мәтінді бүтін санға айналдырады. print(...) нәтижені экранға шығарады. = есептелген мәнді айнымалыға сақтайды.

age = int(input())
print(age + 1)

Кіріс 16 болса, шығыс 17. age — сан сақталған айнымалы.

Арифметика

+ қосады, - азайтады, * көбейтеді, / бөлгенде бөлшек нәтиже береді, // бүтін бөліндіні, % қалдықты, ** дәрежені табады.

print(7 / 2)   # 3.5
print(7 // 2)  # 3
print(7 % 2)   # 1
print(2 ** 3)  # 8

# соңындағы мәтін — түсіндірме, Python оны орындамайды.

Салыстыру және шарт

== тең бе, != тең емес пе, >/< үлкен/кіші ме, >=/<= шекараны қоса салыстыра ма — соны тексереді. Нәтиже True не False.

score = 75
if score >= 50:
    print("Өтті")
else:
    print("Қайтала")

Нәтиже «Өтті». : блокты бастайды; ішіндегі жолға 4 бос орын шегініс қой.

Бірнеше шарт

elif алдыңғы шарт орындалмаған кезде келесі шартты қарайды. and үшін екі шарт та дұрыс, or үшін кемінде бірі дұрыс болуы керек. not мәнді кері аударады.

x = 12
if x >= 10 and x <= 20:
    print("Аралықта")
elif x < 10:
    print("Кіші")
else:
    print("Үлкен")

12 екі шекараның ішінде, сондықтан «Аралықта» шығады.

Жол және тізім

strip() жолдың басы мен соңындағы бос орынды және жол ауыстыруды алып тастайды; ішкі бос орынды сақтайды. split() мәтінді бос орындар бойынша бөліктерге бөледі. map(int, ...) әр бөлікті санға айналдырады, list(...) нәтижені тізімге жинайды.

text = "  2  4  6 \n"
parts = text.strip().split()
numbers = list(map(int, parts))
print(numbers)  # [2, 4, 6]

strip()-тен кейін "2 4 6" қалады. split() үш сөз береді. Сандарды қосу үшін sum(numbers) → 12.

Дайын функциялар

len(x) элемент санын, max(x) ең үлкенін, min(x) ең кішісін, sum(x) қосындысын береді. str(n) санды мәтінге айналдырады; any(...) кемінде бір шарт орындалса True қайтарады.

nums = [3, 7, 2]
print(len(nums), max(nums), min(nums), sum(nums))
# 3 7 2 12

Цикл және сүзу

for элементтерді бір-бірден қарайды; if керегін таңдайды. n % 2 == 0 санының жұп екенін тексереді.

for n in [2, 3, 4]:
    if n % 2 == 0:
        print(n)
# 2, кейін 4

sum(1 for n in numbers if n % 2 == 0) әр жұп санға 1 қосып, олардың санын табады.

Файлды ашу, оқу, жазу

with open(..., encoding="utf-8") as f: файлды ашып, блок біткенде жабады. "r" — оқу (әдепкі), "w" — жаңадан жазу, "a" — соңына қосу. read() барлық мәтінді, readline() бір жолды алады.

with open("input.txt", "r", encoding="utf-8") as f:
    text = f.read().strip()
with open("output.txt", "w", encoding="utf-8") as f:
    f.write(text)
print(text)

Мұнда input.txt мазмұны оқылып, output.txt файлына жазылады. write() экранға ештеңе шығармайды, сол үшін print() бөлек тұр.

Қате және Path

try ішінде қате шығуы мүмкін әрекет тұрады. except FileNotFoundError файл жоқ жағдайын ғана ұстайды. Path(...).read_text() файл мәтінін оқу, write_text() жазу жолын қысқартады. splitlines() мәтінді жолдарға бөледі.

from pathlib import Path
try:
    lines = Path("input.txt").read_text(encoding="utf-8").splitlines()
    print(len(lines))
except FileNotFoundError:
    print("Файл табылмады")

Қосымша жазылымдар

f"{n}" санды мәтін ішіне қояды; " ".join(...) мәтіндерді арасына бос орын салып біріктіреді; ch.isdigit() таңбаның цифр екенін тексереді. [int(line) for line in f if line.strip()] бос емес жолдарды санға айналдырып тізім жасайды.

name = "Аяна"
score = 95
print(f"{name}: {score}")
# Аяна: 95

Кодтағы тырнақша мәтінді белгілейді; жай жақша функция аргументтерін, шаршы жақша тізімді белгілейді. Python үлкен және кіші әріпті ажыратады: Print пен print бірдей емес.
